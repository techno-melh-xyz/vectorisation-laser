Pour la découpe laser

Les chemins SVG du mode Découpe sont fermés, mais cela ne garantit pas que la forme physique soit correcte ou sûre. Si la photo contient un trait ouvert, le logiciel peut tracer la silhouette extérieure de l’encre : inspectez alors particulièrement les éventuels contours doubles. En mode Deux bords du trait, les deux côtés de l’encre peuvent produire deux découpes parallèles. En mode Gravure, les traits sont amincis pour obtenir leur axe central, et peuvent rester ouverts. Vérifiez les dimensions physiques, les petits détails et les parcours dans xTool Studio ou LightBurn avant toute opération.

Les images restent sur votre appareil : aucun téléversement vers un serveur.
